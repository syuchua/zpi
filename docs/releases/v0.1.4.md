# Zpi v0.1.4

This release adds the opt-in Trusted Execution stack (target-scoped policy rules, TUI one-time approvals, OS confinement, child environment isolation, worktree-isolated parallel subagents, and unattended fail-stop mode) along with a cross-platform release installer. Default compatibility behavior remains unchanged.

## Highlights

- **Target-scoped policies, TUI approvals, and structured headless denials.** Persistent `--security-policy` files now support `allow`/`deny` rules for canonical paths (`exact`, `subtree`), commands (`exact`, metacharacter-guarded `prefix`), and network URLs (`exact`, `origin`, `host`). Interactive `--security secure` offers one-time `[y/N]` prompts; headless modes fail closed with redacted structured denial details and record every approval and denial to `--audit-log`.
- **Shared OS confinement and canonical-path file checks.** `--sandbox workspace-write|read-only` (default `workspace-write`, `--sandbox-network off` in `--security secure`) confines `bash`, user shell, `bg_run`, `rg`/`fd`, MCP stdio servers, the TypeScript extension host, and subagent child processes using macOS Seatbelt, Linux Landlock + seccomp-bpf, or `bwrap` fallback. Built-in file tools enforce canonical-path workspace containment and reject symlink escapes. `zpi doctor` reports the detected sandbox backend.
- **Child environment allowlisting and credential isolation.** `--env-isolation strict` (default with `--security secure` or an active sandbox) forwards only a minimal non-credential allowlist plus explicit `--env-allow` entries, isolates child `HOME`/`TMPDIR`, and blocks reads of host credential directories.
- **Worktree-isolated parallel subagents and unattended fail-stop mode.** `--subagent-isolation worktree|auto` runs concurrent subagents in detached git worktrees with read-only parent `.git` metadata and returns bounded `changedFiles` and unified diffs. `--unattended` enforces headless secure mode with an explicit policy file, audit log, OS sandbox, and strict environment isolation, halting immediately on the first denial or workspace boundary violation.
- **Cross-platform release installer.** `install.sh` detects macOS/Linux, x64/arm64, and glibc/musl, verifies the release archive SHA-256 checksum, extracts under `~/.local/opt/zpi`, and atomically updates `~/.local/bin/zpi` without replacing regular files.
