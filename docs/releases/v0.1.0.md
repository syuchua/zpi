# Zpi v0.1.0

Zpi v0.1.0 is an experimental Zig-native terminal coding agent. It provides a standalone CLI and regular terminal UI with no Node runtime requirement for the core agent loop.

## Included in this release

- OpenAI Chat Completions, a text and tool subset of OpenAI Responses, and a text and tool subset of Anthropic Messages.
- Native scrollback-preserving TUI with streaming output, Markdown rendering, session resume, branch navigation, compaction, queued follow-ups, steering, cancellation and background task notifications.
- Built-in file, shell, search, URL fetching, cached content and background task tools.
- Experimental `--mode rpc` with `prompt`, `get_state` and `abort`, bounded JSONL framing, streaming events, cancellation and orderly EOF handling.
- Experimental opt-in native `subagent` delegation with single or parallel child tasks, bounded output, cancellation, deadlines and inherited eligible native tools.
- Explicit-path TypeScript extension hosting for a tested subset of Pi SDK versions `1.5.2` and `1.6.0`.
- Experimental C/Zig native plugin loading with typed values, descriptor checks, tool execution, progress, cancellation and cleanup.
- Explicit MCP stdio servers, Skills, prompt templates, Pi v3 session import and deterministic release archives.

## Compatibility and security boundaries

Zpi has its own session format and native plugin ABI. Its Pi RPC, session import, provider and extension support covers the subsets listed in the [compatibility matrix](../spec/compatibility-matrix.md). Images, OAuth, project trust and approval controls, package management, full TypeScript extension APIs, Rust plugin interoperability and a stable native ABI are outside this release.

TypeScript extensions and native plugins execute with the launching user's OS permissions. Explicitly selected extensions, plugins and MCP servers are trusted executable code. Native plugins run in-process and are not crash isolated. The core binary does not provide a sandbox.

## Verification

The CI matrix targets Linux x64, Linux arm64, macOS x64 and macOS arm64 with Zig 0.17.0. Each target produces a `.tar.gz` archive and matching SHA-256 file. It runs formatting checks, Zig tests, SDK-backed TypeScript fixtures, C/Zig plugin fixtures, context-budget checks and ReleaseSafe archive smoke tests. See the [platform verification records](../spec/platform-verification.md).

## Installation

Use the platform archive and matching `.sha256` file from the GitHub release. Verify the checksum before extraction. Source builds require Zig 0.17.0. See [installation instructions](../install.md) for archive and source workflows.
