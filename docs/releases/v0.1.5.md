# Zpi v0.1.5

This release focuses on out-of-the-box daily usability while keeping Zpi small, fast, and dependency-light: native `web_search` with zero-config Exa, a native Google Gemini API provider, `/cost` and `/context` inspection commands, `zpi auth`/`models`/`mcp` management subcommands, and persistent `mcp.json` configuration.

## Highlights

- **Pure-Zig native `web_search` tool.** Automatically selects Brave (`BRAVE_API_KEY`), Tavily (`TAVILY_API_KEY`), or SearXNG (`SEARXNG_URL` / `ZPI_SEARCH_URL`) when configured, and defaults to zero-config **Exa** (`https://mcp.exa.ai/mcp`, Streamable HTTP JSON-RPC `web_search_exa`) with no API key required (`ZPI_SEARCH_BACKEND=duckduckgo` is also supported). Reuses `web_fetch` SSRF validation and `network.connect` policy/audit enforcement.
- **Native Google Gemini API client.** Built-in `gemini` provider (`gemini-generate-content` via `streamGenerateContent?alt=sse`, default `gemini-2.5-flash`, `GEMINI_API_KEY` / `GOOGLE_API_KEY`) authenticates via `x-goog-api-key` header (never URL query strings) and supports streaming text/thoughts, `systemInstruction`, multi-turn `contents`, `inlineData` images, sanitized `functionDeclarations`, `functionCall`/`functionResponse` round-trips, `thinkingConfig`, and `usageMetadata` (including `cachedContentTokenCount`).
- **`/cost` and `/context` interactive commands.** Tracks per-session request counts, input/output tokens, and cache read/write tokens across OpenAI, Anthropic, and Gemini, estimates USD when pi-compatible `models.json` `cost` pricing is configured, and breaks down active context window usage by category.
- **Out-of-box `zpi auth`, `zpi models`, and `zpi mcp` CLI subcommands.** `zpi auth status|set|remove` manages provider credentials via `--api-key-env` or `--stdin` with atomic `0600` writes and zero secret echoing; `zpi models list|set-default <provider>/<model>` manages defaults in `settings.json`; `zpi mcp list|add|remove` manages `~/.zpi/agent/mcp.json`.
- **Restrained `mcp.json` configuration with project trust gating.** Loads user-level `~/.zpi/agent/mcp.json` by default (`--no-mcp-config` disables it) while keeping project `.zpi/mcp.json` / `.mcp.json` opt-in behind `--trust-project-mcp`. Configured MCP servers pass through the same `mcp.start` + `process.exec` capability checks, audit logging, and OS sandbox confinement as `--mcp-stdio`.
