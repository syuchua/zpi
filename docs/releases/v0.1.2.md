# Zpi v0.1.2

Zpi v0.1.2 adds local image input and completes fullscreen transcript selection, while improving session workflows and terminal rendering.

## Highlights

- **Image input.** Attach up to eight local PNG, JPEG, GIF, or WebP images with `--image PATH` alongside a prompt. The total image payload is limited to 2 MiB. OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages requests encode the supplied images; Zpi session record v3 preserves image content.
- **Fullscreen transcript selection.** Drag with the left mouse button across visible transcript rows and release to copy the selected terminal cells. Wrapped output, ANSI styling, wide characters, combining marks, reverse-direction drags, search, and live streaming are supported. A short `Copied` notice appears after successful selection copies.
- **Preserved terminal interactions.** Plain clicks continue to fold tool output and navigate pinned messages or Jump to latest. Keyboard input, scrolling, navigation, frame changes, and resize cancel stale drag gestures. Regular terminal mode retains native selection and scrollback.
- **Session workflow.** `/new` starts a fresh session without exiting Zpi. Fullscreen rendering, search navigation, startup feedback, and session restoration receive additional fixes.

Mouse selection uses xterm SGR reports with button-motion tracking. Clipboard helpers are `pbcopy` on macOS, `wl-copy` on Wayland, and `xclip` on X11. Linux desktop clipboard behavior was not exercised in the macOS release-validation environment. Interactive image attachment, image input through RPC or extensions, and pi session image import/export remain unsupported.

## Downloads

Choose the archive for your OS, architecture, and C library. Six builds are provided: Linux x64 and arm64 for glibc 2.17 or later, Linux x64 and arm64 for musl, macOS x64 with a 10.15 deployment target, and macOS arm64 with an 11.0 deployment target. Verify the matching `.sha256` file before extraction. Source builds use Zig 0.17.0.
