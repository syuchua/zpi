# Zpi v0.1.1

Zpi v0.1.1 improves the native terminal UI for reading long sessions, finding previous messages, and copying assistant replies.

## Highlights

- **Incremental fullscreen rendering.** Streaming and editor updates redraw changed rows, reducing terminal output. Resize and terminal invalidation trigger a full repaint.
- **Transcript search and navigation.** Use `/search` or `Ctrl+F` at an empty prompt to search retained transcript rows. Use `Up`/`Down` or `Ctrl+P`/`Ctrl+N` to cycle matches. `Esc` restores the previous view. Outside search, `Ctrl+P`/`Ctrl+N` at an empty prompt jump between user messages. The pinned user message is also clickable.
- **Copy the latest reply.** Use `/copy` or `Ctrl+X` to copy the latest assistant text from the active session branch as Markdown. Clipboard support uses `pbcopy` on macOS, `wl-copy` on Wayland, or `xclip` on X11.
- **Inline tool output.** Long results start folded to a two-row preview by default. Click a card to toggle it or use `Ctrl+O` to toggle all results. Set `toolOutputsExpanded` to `true` to start with expanded output.
- **Everyday fixes.** Eligible transient provider errors are retried before a final error appears. Zpi discovers skills in `~/.agents/skills`, and `/quit` or `/exit` prints the saved session's JSONL filename after restoring the terminal.

ANSI-capable interactive terminals default to fullscreen. Use `--tui-mode regular` for native terminal scrollback and text selection. For a headless source build, use `zig build -Dtui=none`.

## Downloads

Choose the archive for your OS, architecture, and C library. Six builds are available: Linux x64 and arm64 for glibc 2.17 or later, Linux x64 and arm64 for musl, macOS x64 with a 10.15 deployment target, and macOS arm64 with an 11.0 deployment target. Verify the matching `.sha256` file before extraction. Source builds use Zig 0.17.0.
